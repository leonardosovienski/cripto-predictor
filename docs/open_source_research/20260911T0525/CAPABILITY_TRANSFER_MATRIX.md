# Capability transfer matrix

Prioridade qualitativa: utilidade imediata, menor condição necessária testável, custo de integração e independência de dados financeiros ausentes. Os 20 itens são lacunas ou necessidades específicas; não são 20 capacidades totalmente ausentes. Os primeiros cinco foram implementados, os seguintes cinco constituem a fila principal de transferência. Os demais permanecem delimitados, sem discovery amplo.

G11–G20 usam fontes adjacentes e o survey herdado para orientar necessidades, sem afirmar que a referência da célula já resolve o gap completo. Referências herdadas não foram promovidas a inspeção atual. Essa distinção impede extrapolar uma inspeção de função a uma certificação de produto.

As diferenças cosméticas identificadas foram vocabulário (`run` versus `trial`), formatos tabulares versus listas JSON e grafia de estados `CANCELED`/`CANCELLED`. Essas diferenças não justificam substituir o núcleo. Registro genérico e registro científico têm contratos diferentes e coexistem.
