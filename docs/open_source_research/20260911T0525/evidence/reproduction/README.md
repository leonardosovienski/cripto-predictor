# Scripts arquivados

Estes scripts registram como a rodada original foi preparada e verificada. Não os execute nesta pasta de evidências: alguns calculam a saída a partir de `__file__` e podem sobrescrever recibos históricos. Para reproduzir, copie-os para uma pasta nova em `C:\Cripto\operacao\relatorios`, ajuste os caminhos e preserve os recibos originais. `prepare.py` consulta código externo e cria uma baseline nova; não serve para verificar a baseline congelada.

Para uso corrente do toolkit, prefira os comandos documentados em `GarimpoInvestimentos/research/README.md` no checkout. O comando `research run` registra uma execução nova sem sobrescrever runs concluídos.
