# Errata consolidada — 2026-08-21

> **Por que este documento existe.** O projeto preserva registros datados sem
> reescrevê-los: correção entra como errata ou adendo, nunca como edição do texto
> original (é assim que `RELATORIO_FINAL.md` §9 e as erratas de `HYPOTHESES.md`
> funcionam). Vários documentos de jul/2026 continuam corretos *para as datas que
> carregam*, mas afirmam coisas que deixaram de valer. Este arquivo é o índice único
> dessas divergências, para que cada documento datado precise apenas apontar para cá
> em vez de repetir a mesma correção sete vezes.
>
> Nada aqui invalida os vereditos científicos dos documentos originais — os NO-GO de
> H1-H3 e H5 seguem de pé, com os mesmos números. O que mudou foi o estado de
> engenharia, de branches e do incidente de segurança.

Estado corrente canônico: [../README.md](../README.md) e
[RELATORIO_FINAL.md](RELATORIO_FINAL.md) §9.
